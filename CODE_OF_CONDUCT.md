# Code of conduct

Mlpipelinecheck is a technical project. People who contribute, review, or ask for help are expected to:

- criticize the code, the evidence, and the documentation, and leave personal attacks out of it
- read the finding limitations before claiming a result proves leakage or safety
- keep other people’s data out of issues, examples, and commits
- say when a result was not actually run

Harassment, discrimination, and publishing someone else’s private data are not acceptable.

This repository has no public reporting address and no separate moderation team. Report a concern to the repository maintainers through the channel where the project is hosted. If there is no maintainer contact, do not send personal data to an invented address.

Maintainers may remove comments, issues, or contributions that break these expectations.
